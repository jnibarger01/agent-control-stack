## Release blockers outside the code slices

- **npm audit.** `npm run security:audit` (`--audit-level=high`) exits 1. On November 18, 2026, the full tree had 6 high and 15 moderate findings, and the production-only tree had 4 high (`vite`, `picomatch`, `tinyglobby`, `fdir`) and 4 moderate (`hono`, `@hono/node-server`, `@vercel/queue`, `minimatch`). The high fixes require Vitest 5 or a Vite major change, and `picomatch` 4.0.7 is still the latest release. The gate stays enforced. A Node-free Rust release image would remove the runtime exposure but not the build-tree findings.
- **Unknown attempts and retry.** An unprovable isolation outcome now ends the attempt as `unknown` (`isolation_unknown`) instead of `failed`. `createAttempt` still does not refuse a new attempt while an earlier attempt is `unknown`, and the store has no explicit reconciliation record that clears it. The expired-lease path relies on the same behavior. Changing this changes lifecycle semantics and needs a migration number reservation (a draft PR, which is a remote write), so it is recorded rather than changed here.

## Next slices in dependency order

1. Certify the Rust supervisor and relay on more host profiles, stream raw output over a separate descriptor to remove the base64 cost, then propose Rust as the default behind its rollback flag. (The egress relay port is done: `45f9b255`, `f3539c74`.)
2. `acs-core`: port canonical encoding, hashing and audit-chain verification first (read-only, differential against `packages/shared` and `packages/work-items` fixtures). Then the SQLite store with fenced transitions, approvals and grants, against copied historical databases.
3. Worker IPC and the `acs-worker` and `acs-scheduler` binaries over `acs-core`.
4. `acs-gateway` (HTTP, SSE, MCP, OAuth) over `acs-core`, verified with `contracts/public/v1`, the compatibility baseline and the Jace Commander and Codex Swarm contract suites in both mixed-version directions.
5. `acs` CLI, backup and drill commands, the Rust release image, provenance, a supported-target matrix and a timed rollback rehearsal.
