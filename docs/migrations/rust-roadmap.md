## Next slice for Linux scope supervision

Select the common launch and termination lifecycle in `packages/sandbox/src/linux.ts` and `packages/sandbox/src/engine.ts`. Each retains its policy, invocation builder and egress profile. Common scope supervision removes duplicated timeout, cancellation, signal escalation, capture and cleanup logic. The broader sandbox and worker IPC are later slices.

- **Request and ownership.** After verifying the existing authority receipt, ACS passes a bounded versioned request over a private parent-child channel. Include attempt and lease correlation, the workspace-bound invocation rendered by ACS, output and timing limits, a unique scope reference and the explicit environment allowlist. Bind cancellation to that invocation. Keep the control channel out of the sandbox child. Pass bounded output to the existing redactor and cap capture and frames independently.
- **Outcome.** Return one observation with correlation, exit status or signal, timeout or cancel trigger, byte counts, truncation and cleanup status. ACS validates it before result acceptance under the current fence. An exit code establishes only process observation. A disconnect or missing cleanup proof remains unknown and requires governed reconciliation.
- **Tests.** Record TS reference results for verified exit, launch failure, cancellation before and during start, timeout/cancel races, delayed scope disappearance, nonzero exit, signal, interrupted parent and malformed responses. Run disposable scopes to prove descendant cleanup, resource limits and output bounds. Reject late results across fencing epochs. Exercise version rollback with an unresolved scope and verify the attempt stays blocked from retry.
- **Isolated implementation.** `rust/scope-supervisor` implements the termination decisions over a bounded, sequenced stdio protocol and is exercised against the TypeScript reference. The sandbox parity harness owns elapsed time and supplies close and signal-completion events. Moving the lifecycle channel into a live attempt requires fence binding, validation of requested effects, and reconciliation when the helper disconnects. [Coordinator protocol and test commands](../../rust/scope-supervisor/README.md)
- **Readiness.** The TypeScript backends share termination coordination, bounded output and scope verification. Cleanup after SIGKILL requires a fresh terminal scope status. Engine startup waits for its private egress relay and refuses to launch if the relay cannot listen. Use the deterministic and disposable-scope results as the TypeScript reference. Live Rust integration still requires the attempt- and fence-bound handoff, supervisor-disconnect recovery and parity across supported hosts. Jace Commander lifecycle and output changes are open in draft.
