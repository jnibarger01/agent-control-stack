# agent-control-stack v0.1.0-alpha

Release mode: dry-run control-plane alpha.

## Allowed Claims

- Policy evaluation for requested work-item actions.
- Exact action-hash approval lifecycle with request hashes, expiry, and consumed approval records.
- Tamper-detecting audit chain; writes fail closed after startup or `/health` detects invalid audit history.
- Local-boundary worker claim flow with compare-and-swap status transitions and authenticated, worker-bound, lease-bound result submission.
- Immutable execution results with transactional state transitions, durable idempotency, and audit evidence.
- Immutable retry and clone lineage with fresh action hashes and normal policy/approval re-evaluation.
- Dry-run execution simulation; worker result payloads and terminal audit events carry `executionMode: "dry_run"`.

## Forbidden Claims

- Real command execution.
- Sandbox isolation.
- Hardened worker runtime.
- Production-safe machine mutation.
- Production remote connector mode.

## Known Limitations

- Per-action approval UI rendering is minimal; full policy-context rendering and separate per-action detail controls are a fast-follow.
- Dashboard health is not yet backed by a richer `/health` display.
- Error envelopes are not unified across all surfaces.
- The real sandbox and actual command execution remain disabled.
- External connector proof remains separate from local worker-lifecycle proof.
- Per-principal result rate limiting is not yet present because the gateway has no existing rate-limit subsystem; body, field, JSON-depth, and artifact limits are enforced.
- Runbook coverage is thin.
- The execution slice is planned to use bubblewrap and must pass realpath-containment, symlink-escape, env-allowlist, network-denial, and resource-limit tests before any execution claim.
