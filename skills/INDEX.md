# Compounding skills

Store reusable, repository-specific workflows here. Each skill must include an
acceptance check and a dated changelog entry. Start from `_templates/SKILL.md`.

- `eval-baseline/` — establish and compare fixed-corpus, costed baselines.
- `independent-verification/` — run isolated maker-verifier loops and persist redacted evidence.
- `bounded-orchestration/` — run isolated multi-agent patterns with complete receipts and hard caps.
- `procedural-learning/` — retrieve verified skills before engineering work; promote only from validated success.
