# Licensing — Explicit Owner Decision

**Status: No license selected.**

This repository is currently **unlicensed**. No license has been chosen, and
nothing in this repository grants anyone any rights to use, copy, modify, or
redistribute the source code or any binaries built from it.

## Why this file exists

The October 12, 2026 independent review flagged the absence of a license as a
release-readiness gap (finding F9). This file records that gap as an explicit
owner decision rather than leaving it implicit.

## What must happen before publishing

Before publishing binaries or accepting outside contributions, the owner must:

1. Select a specific license (for example, MIT, Apache-2.0, or GPL-3.0) — this
   decision is a legal and business choice, not an engineering one.
2. Add the chosen license text as `LICENSE` (the conventional filename) or
   `LICENSE.<name>`.
3. Update this file to record the selection and remove this placeholder.

## Until then

- Treat all source code, documentation, and artifacts as **proprietary and
  confidential**.
- Do not accept contributions under any implied license.
- Do not publish binaries without a stated license.
